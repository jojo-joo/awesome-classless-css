# Awesome Classless CSS
all classless css frameworks in one page for comparision & testing & prototype selection.
open [demo](https://jojo-joo.github.io/awesome-classless-css/) which hosted in git pages directly in a browser.

## Why Using Classless CSS
considering in embeded system developing, classless css could bring:
- Smaller Size: Due to resource constraints in MCU, we need to minimize our footprint as much as possible.
- Easier to Develop: A simple HTML page whose appearance can be changed by switching classless CSS is convenient for embedded developers who are unfamiliar with H5 technologies.

## Why This Project
- Quick Estimation: just click  top-left corner button to switch classless css framework to estimate all the classless css in the world.
- Ranking: To comprehensively evaluate feature completeness, compatibility, and adaptability across frameworks, helping engineers make faster technology choices.
